# ================= HUGGING FACE MODELS =================
# For vLLM and SGLang: models in .safetensors format that fit a 32 GB GPU
# (RTX 5090) with room left for the conversation. The size after each name is
# the download, which is also roughly what the model takes in VRAM.
# GGUF models are for Ollama: add them to stack/downloaders/ollama/models.txt.
# Mark models that need an access token in .env with GATED|, e.g.
# GATED|org/model. None of the models below needs one.
